# DiversScout Viewer

## 概要
`diversscout_viewer` は、都市のバリアフリー情報や移動データを収集・可視化するためのビューアアプリケーションです。
車椅子トラッカーやバリアロガー等のデバイスから収集された位置情報・移動データを地図上にマッピングし、アクセシビリティの向上や都市のバリアフリー状況の把握を支援します。

## 主な機能
- **地理空間データの可視化**: OpenStreetMapをベースとした地図インターフェース上で、移動経路やポイントデータ（段差、傾斜などのバリア情報）を直感的に表示します。
- **リアルタイムデータ連携**: Supabaseと連携し、データベースに蓄積されたロギングデータを効率的に取得・表示します。
- **マルチデバイス対応**: 車椅子トラッカーやバリアロガーなど、様々な移動体から収集された多様なフォーマットのデータを統合的に扱います。
- **バリアフリー情報の共有**: 収集したデータを可視化することで、誰もが安全に移動できるルートの発見や、インフラ整備のための基礎データとして活用できます。

## 利用技術・スタック
- **フロントエンド**: HTML, CSS, JavaScript
- **地図基盤**: OpenStreetMap, Leaflet 等の地理空間ライブラリ
- **バックエンド・データベース**: Supabase

## システムの目的と構成
本システムは、各種トラッカーやロガーから収集したセンサーデータ（GPS位置情報、傾斜、加速度など）を中央データベースに蓄積し、フロントエンドのビューアを通じて視覚的にマッピングします。
これにより、特定のルートにおけるバリア（障害物や急な坂道など）を可視化し、車椅子ユーザーやベビーカー利用者などの移動をサポートするための情報基盤として機能します。
